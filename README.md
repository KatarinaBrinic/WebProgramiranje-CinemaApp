# CinemaApp 🎬

CinemaApp is a web application developed as a university project for managing cinema operations. The application provides functionality for managing movies, screenings, users, reservations, and ticket purchases through a backend system integrated with a relational database.

The main goal of the project was to design and implement a complete application while focusing on backend development, database modeling, and maintaining clear relationships between different entities.

## Features

- User management
- Movie management
- Screening scheduling
- Reservation and ticket purchasing system
- Relational database integration
- Backend business logic for managing cinema operations

## Technologies Used

- Backend: Java / Spring Boot / Node.js / .NET
- Database: SQL relational database
- Frontend: HTML, CSS
- Version Control: Git & GitHub

## Database Design

The application uses a relational database structure with separate entities for:

- Users
- Movies
- Screenings
- Reservations
- Tickets

Primary and foreign keys were used to maintain relationships between entities and ensure data consistency. The database was designed to reduce redundancy and support efficient data retrieval.

## Project Structure

The project is organized into separate components to keep the code maintainable and easier to extend. Backend logic is separated from database operations and application functionality.
